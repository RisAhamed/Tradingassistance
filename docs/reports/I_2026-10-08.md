# Phase I — AI proposals with human approval (guarded writes)

## 1. Phase summary

Phase I makes optimizer output reviewable without giving the AI any new
power to trade, enable execution, or touch configuration. The tuner keeps
writing JSON under `logs/proposals/`; the AI supervisor gains read tools
(`list_proposals`, `get_proposal`), a pending-only writer
(`propose_strategy_change`, LOW_RISK_CONTROL), and a permission-gated
applier (`apply_proposal`, HIGH_RISK_CONTROL, default denied) that calls
the SAME shared routine as the human API. Humans list/apply/reject through
`GET/POST /api/proposals*` (state changes require `?confirm=yes`) and a
dashboard card; applying writes an atomic overlay file
(`configs/applied_overrides.yaml`, code-owned, gitignored) that
`load_config()` deep-merges at next startup (restart required), with
backup + sidecar + `PROPOSAL_APPLIED` event + `ai_actions` persistence.
`configs/config.yaml` is never written by code (sha256-pinned by tests).

## 5. Overlay design note

Merge order: `config.yaml` → `applied_overrides.yaml` (deep, overlay wins)
→ env overrides → `AppConfig` validation. Missing overlay file: zero
behaviour change (log line says `none`). Invalid overlay: `ConfigError`
at load, startup fails loudly. Apply-then-restart: the next `load_config`
sees the merged values; deleting the overlay (or restoring a backup from
`applied_dir/*_backup.yaml`) reverts on the following restart. No
rollback endpoint by design (documented limitation).

## 10. Known limitations

1. No dedicated rollback endpoint — revert via deleting/restoring the backup YAML in `applied_dir` (documented, tested manually).
2. The overlay file is a second source of truth the human must be aware of; `CONFIG OVERLAY=` log line + dashboard counts mitigate surprise.
3. AI review is human-triggered (`POST /api/ai/review_optimization`), never automatic.
4. Overlay params are applied as written — schema-validated, but semantic review remains human (by design).
5. `*.log` is repo-gitignored, so the transcript needed `git add -f` (same convention as prior phases).
